# Languages

The site shows English or Hungarian. English is the source; adding a language means adding one folder of texts and one line in a list. See ADR 0003 for why this library and this shape.

## How it works

- `src/i18n/index.ts` starts `i18next` with English bundled, so the first render already has its texts. Other languages are separate chunks, fetched the first time they are chosen (`loaders`).
- The choice is `languageStore` (`nflsw:v1:language`): `auto` (the default, follows the browser's language list), `en` or `hu`. Settings → General → Language changes it with Save, like every other setting. `applyLanguage()` switches the open page without a reload and sets `<html lang>`.
- Every text lives in `src/i18n/en/<area>.ts` (areas: `shell`, `leagues`, `sync`, `camp`, `settings`, `privacy`) and its translation in `src/i18n/hu/<area>.ts`. The Hungarian file is typed `Messages['<area>']`, so a missing or extra key does not compile (`npx tsc --noEmit`). `src/i18n/i18n.test.tsx` also checks that a translation keeps every `{{value}}` and `<tag>` of the English.
- Keys are checked too: `t(($) => $.shell.nav.players)` is a function over the English texts, so a wrong key is a compile error and renaming one is a refactor.

## Using it

```tsx
const { t } = useTranslation();
<button>{t(($) => $.shell.pause.pause)}</button>                       // a text
t(($) => $.sync.added, { count: 3 })                                    // a count: keys added_one / added_other, text '{{count}} starters'
t(($) => $.leagues.lastImported, { when })                              // a value: 'Last imported {{when}}'
<Trans t={t} i18nKey={($) => $.sync.step} components={{ b: <strong />, a: <a href="…" /> }} />   // 'Click <b>Sync</b> or <a>read more</a>'
```

Outside a component (error messages, text built in plain functions) use the instance: `i18n.t(($) => $.leagues.errors.notFound)` with `import { i18n } from '../i18n'`. That reads the language at that moment; do not call it at import time or store the result.

Rules that keep the two languages in step:

- Never build a sentence from pieces (`'Added ' + n + ' starters'`). Word order and plurals differ per language. One text with `{{values}}`, and `_one` / `_other` keys for counts.
- Dates and numbers: pass `i18n.language` to `toLocaleString` and friends, not `[]`.
- Not translated: ESPN's own data (player and team names, play descriptions, headlines), position codes (QB, RB, …), the site name, and the mascot's name (a setting the user can change, passed in as a value).
- A text that is user data is never a key.

## Hungarian style and words

Informal (tegező), short, plain, the way a sports app talks. Established English football words stay when Hungarian fans use them (touchdown, sack, interception, field goal, fantasy). Keep these terms the same everywhere:

| starter(s) | kezdő(k) |

| import / export | importálás / exportálás |

## Adding a text

1. Add the English to `src/i18n/en/<area>.ts`, then the Hungarian to `src/i18n/hu/<area>.ts` (`tsc` tells you where it is missing).
2. Use it with `t(($) => …)`.
3. A component test that reads English text keeps working; for the Hungarian add one with `await inHungarian()` (`src/test/render.tsx`) before rendering.

## Adding a language

1. Add its code to `LANGUAGES` and its own name to `LANGUAGE_NAMES` (`src/i18n/index.ts`), and a loader line to `loaders`.
2. Copy `src/i18n/hu/` to `src/i18n/<code>/` and translate; `tsc` and `i18n.test.tsx` show what is missing or broken.
3. Add the captions for the sync tour video (below) and extend the glossary above for its terms.

## Videos

The sync tour video is narrated in English only. Captions come as one WebVTT file per language in `public/captions/` (`sync-tour.<code>.vtt`, plus `sync-tour.en.vtt`), attached as `<track kind="captions" srclang="…" label="…">`. The browser's own caption menu lets the viewer pick; the track for the current site language is the default one. A caption file is the narration, line by line, with the times at which each line starts and ends: `ffmpeg -i public/sync-tour.mp4 -af silencedetect=noise=-35dB:d=0.4 -f null -` lists them.
