# Stat Watch ESPN Connector (development)

This Manifest V3 Chrome extension reads only `mSettings` from ESPN's fantasy API. The app first tries an anonymous request. When ESPN denies it, the extension opens or reuses a `fantasy.espn.com` tab, then makes the API request from its service worker using the browser's request credential handling. Its host permissions are limited to the ESPN fantasy site and settings API. It strips the response to league ID, season, scoring items and lineup slot counts before replying. It does not use the `cookies` permission or store session data. If ESPN denies access, check the active account and league membership, sign in if needed, and choose **Connect ESPN and retry** in Stat Watch. Disconnecting an imported profile removes its source link but leaves the connector installed; disable or remove the connector in Chrome's extension settings to revoke it.

The development manifest is restricted to `http://localhost:5173`. To build it, run `node manifest.build.mjs`; load the generated `dist` directory from `chrome://extensions` with Developer mode enabled. Copy the generated extension ID to `.env.local` as `VITE_ESPN_CONNECTOR_ID=<id>`, then restart Vite. This local installation step has not been performed or authenticated API access verified.

For another app origin, set `STAT_WATCH_APP_ORIGIN` to that exact `https://` origin or a localhost origin and run `node manifest.build.mjs`. The generated manifest is local build output and should not be committed. A production app origin and extension distribution ID must be selected before publishing. Chrome is the only planned initial browser; Firefox is unsupported until its connector permissions and messaging are separately implemented and reviewed.

The service worker validates the exact origin list embedded in the manifest and constrains league ID, season, request ID and nonce. It constructs a fixed ESPN API URL, enforces response size limits, strips team/player/user data and returns an allowlisted payload. Treat the ESPN response as untrusted input and validate it again in the app before preview or persistence. The credentialed fetch has not yet been verified in a browser; confirm that the user's ESPN session is included under the browser's cookie policy before treating private imports as supported.
